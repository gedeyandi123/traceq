# Web UI architecture: Tailwind CSS v4 over semantic tokens, owned Radix primitives, Lucide icons, and docs/DESIGN.md

Decided 24 November 2026, superseding [ADR 0011](0011-web-styling-css-modules-over-tokens.md) after a live-browser audit of the `TP-201` demo across `1366x768`, `1440x900`, and `390x844`, an enterprise GMP/QA UI review, and a fresh-context adversarial review (`doubt-driven-development`).

**Why ADR 0011 is superseded.** The incremental CSS Modules + native `<details>` approach inside 6-column tables failed above-the-fold orientation (roughly 68% of the `1366x768` viewport was consumed by headers, intro copy, and filters before the first data row), exploded row height (up to ~72% of the viewport) when inline evidence and decision forms opened, separated Required vs Observed values across columns, and cannot support Step 5b ([ADR 0013](0013-execution-results-judged-by-code-deviations-opened-by-code.md)): multi-attempt execution histories, versioned corrections with Reason for Change, multi-instrument calibration validation, hash-bound Witness confirmation, and 4-way separation-of-duties Deviation workflows. The horizontal tab bar also overflows at `390px` and cannot scale to 7–8 screens.

**Styling and semantic tokens.** `web/` adopts Tailwind CSS v4 (`@tailwindcss/postcss` and `postcss.config.mjs`) with `@theme` and `--color-*: initial` in `web/src/app/globals.css`. `white`, `black`, `transparent`, `current`, the Precision Clinical Slate-Teal surface/accent tokens, the six Coverage classes, and Step 5b Execution/Deviation statuses are declared explicitly in `@theme`. During incremental migration, legacy unlayered element rules in `globals.css` (including `.muted` and `.visually-hidden`) are wrapped in `@layer base` / `@layer components` with scoped selectors so they never override `@layer utilities` or leak onto Radix triggers. Mixing legacy `*.module.css` classes and Tailwind utilities on the same element is forbidden.

**Owned UI primitives and icons.** Interactive primitives live as owned source files in `web/src/components/ui/` built over the unified `radix-ui` package (`Dialog`, `Sheet`/`Drawer`, `Tabs`, `Select`, `Tooltip`, `DropdownMenu`) and `lucide-react` icons. Every owned file must pass TypeScript `strict` + `noUncheckedIndexedAccess` and ESLint (`jsx-a11y`, `react-hooks`) with zero suppressions (`tests/test_boundaries.py`). Adding `experimental.optimizePackageImports: ["radix-ui"]` in `web/next.config.ts` will be verified empirically in the prototype branch before landing.

**Server-first data loading, thin client islands, and i18n.** Server Components continue to own data fetching, using `React.cache` per-endpoint fetchers shared across route-group layouts and pages, with `revalidatePath("/runs/[runId]", "layout")` on mutations so sidebar badges stay fresh. `web/src/app/layout.tsx` adds `<NextIntlClientProvider>` with scoped client namespaces so interactive client islands (`Drawer`, `SplitPane`, `Sidebar` mobile drawer, `PDF` modal, and Step 5b dynamic forms) can use `next-intl` without bloating the RSC payload. Forms inside drawers and split panes migrate from `redirect()` to React 19 `useActionState` + `revalidatePath` returning `{ ok, error, values }` with controlled or echoed inputs (preventing React 19 uncontrolled form resets on `422`/`409` responses) and a dirty-form guard before switching items.

**Self-hosted, offline-first, and CSP.** All CSS, UI primitives, icons, and fonts remain 100% bundled locally with zero external CDNs; `@fontsource-variable/inter` stays loaded via `next/font/local`, and the UI remains light-theme only. Radix UI (`react-remove-scroll` and Popper) relies on `style-src 'self' 'unsafe-inline'` already present in `web/next.config.ts`; if `'unsafe-inline'` is ever removed from `style-src`, a CSP nonce or `style-src-attr 'unsafe-inline'` will be required. `web/next.config.ts` declares `frame-src 'self'` explicitly, and FastAPI document endpoints (`src/traceq/runs/api.py`) add `Content-Security-Policy: frame-ancestors 'self'` plus `Cache-Control: private, max-age=300` and `ETag` so inline PDF previewing avoids repeated SHA-256 re-hashing on every page jump.

**Design SSOT and colour-literal guard.** [docs/DESIGN.md](../DESIGN.md) is the single visual and UX source of truth. `web/src/colour-literals.test.ts` is migrated from scanning only `*.module.css` to scanning `.tsx` and `.css` files, forbidding arbitrary colour classes (`bg-[#...]`, `text-[rgb(...)]`), inline colour styles, and hex SVG `fill`/`stroke` literals outside the `@theme` block of `globals.css`. Vitest (`web/vitest.config.ts`) disables PostCSS/Tailwind CSS transforms (`css: false`) and uses fully typed `jsdom` polyfills in `web/src/test/setup.ts` with zero `@ts-expect-error`.

## Consequences

- `AGENTS.md` §2 and `web/src/colour-literals.test.ts` are updated to reflect ADR 0014 and `docs/DESIGN.md`.
- Interactive work (drawers, split panes, modals, PDF pre-checks, Step 5b forms) lives in thin, keyboard-accessible client islands while Server Components and Server Actions retain data, auth, and audit ownership.
- Existing Vitest suites that couple to `within(getByTestId(reqId))` and `<details>`/`<summary>` DOM structure migrate slice by slice to behavioural and WAI-ARIA role/name assertions (`screen.findByRole(...)`).
- All visual tokens, screen anatomies, and GMP presentation rules (such as `fail` precedence over `ambiguous`) are governed centrally by `docs/DESIGN.md`.

## Considered Options

- **Keep ADR 0011 (CSS Modules + native `<details>` + zero client libraries):** rejected. Fails above-the-fold density, couples evidence/forms to narrow table cells, and cannot ergonomically support Step 5b multi-attempt, multi-instrument, Witness, and Deviation workflows.
- **External styled component suites (MUI, Chakra, Ant Design):** rejected. Bring runtime CSS-in-JS or rigid styling opinions, conflict with thin server-first bundles and CSP, and are harder to tailor to regulated GMP workflows than owned `radix-ui` + Tailwind v4 primitives.
- **Client-side `pdfjs-dist` canvas viewer from day one:** deferred. Adds ~130–450 KB gzipped JS and requires `worker-src 'self' blob:`. Same-origin `<iframe>` inside an `85vw` modal with a `HEAD` MIME/status pre-check and `.xlsx`/404/mobile fallbacks satisfies citation inspection with zero added JS bundle.
- **Dark theme / `prefers-color-scheme` support:** rejected. Document review, printed/projected demos, and WCAG contrast verification favour a single light-mode Precision Clinical Slate-Teal palette.
